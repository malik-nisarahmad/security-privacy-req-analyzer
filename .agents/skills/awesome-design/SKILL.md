# Awesome Design: Utilitarian Minimalism & High-Taste UI Systems

## Principles
1. **Macro-Whitespace & Focus**:
   - Establish calm visual hierarchy with spacious layout divisions.
   - Clean separation of concerns between navigation, content cards, and contextual actions.

2. **Component Conventions**:
   - **Navbar**: Floating or sticky glassmorphism bar with subtle backdrop-filter blur (`backdrop-blur-md bg-zinc-950/80 border-b border-zinc-800/60`).
   - **Sidebar**: Clean, utilitarian left-docked rail with categorized links, item counters, status pills, and user card.
   - **Badges**: Pill-shaped, small typography (`text-xs`), uppercase with wide tracking (`tracking-wider`).
   - **Form Controls**: Crisp 1px border, dark background (`bg-zinc-900/60`), subtle focus rings (`focus:ring-1 focus:ring-zinc-400 focus:border-zinc-400`).
   - **Tables**: Clean border-collapsed rows with subtle hover highlights, monospace columns for identifiers.

3. **Information Density with Breathing Room**:
   - High information density does not mean cluttered text. Use grid alignment, clean column widths, and micro-dividers to keep complex data readable.
